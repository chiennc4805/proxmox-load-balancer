Clone VM

Lab hiện tại đặt IP tĩnh 172.20.11.100 trong Windows và không có DHCP. Bản clone sẽ giữ IP này nếu bạn chưa cấu hình lại trong guest. Chỉ nên bật một VM dùng IP đó tại một thời điểm.

Clone sang node khác cần template trên shared storage và bridge mạng phù hợp tại node đích.

Cấu hình scheduler (admin)

Scheduler dùng mọi node online từ Proxmox. Chỉ bật node trong cluster khi storage và bridge mạng đã sẵn sàng nhận VM.
